# Apollo baseline provenance

The implementation in `apollo-base/` was imported from the privacy-reviewed public Apollo r5 tree at commit `55cf5ef5f6a228b6749540b29b1701dbb1cfadaa`. The old repository history is preserved separately in a verified local git bundle. Source, services, kernel patches, test tools and recovery notes are retained here; historical KDE screenshots and publication workflows are excluded. No firmware or partition backups are included.
