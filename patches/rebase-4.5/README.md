## R12 input provenance and limits

The [origin manifest](linux-apollo-input-origin.json) records the kernel target, patch checksum and original [AW8697 v3 driver submission](https://lkml.iu.edu/hypermail/linux/kernel/2610.1/12414.html) / [binding submission](https://lkml.iu.edu/hypermail/linux/kernel/2610.1/12284.html). The complete 760-line driver is unchanged from Git blob `9f703f81df2131700145d96e866e2d75b4d212f0`, with the copyright notices of **Armandas Kvietkus, Griffin Kroah-Hartman and AWINIC Technology** preserved. It is a review-submission backport, not a claim of upstream merger. The SPI driver retains its original Samsung Electronics / Andi Shyti attribution and GPL-2.0 notice.

The new DTS includes the existing public Apollo board source; it is not an Android device-tree dump. No per-unit motor calibration is included. The kernel patch does not package the userspace `uaccess` rule or distribute a runtime, boot image or firmware. R12 booted runtime `20261101-4` and added the rule in RAM; a v5 package was prepared but not boot-tested. R13 below later tests a complete RAM boot of v6 with the rule included. See [R12 lab notes](../../docs/validation-2026-11-01.md#r12--physical-rumble-and-infrared-detection).

An offline ARM64/QEMU check described in the manifest examined the SPI inactive-tail behavior. The R12 phone test only queried LIRC capabilities. Neither that fixture nor device detection establishes optical IR emission or remote-control operation.

## R13 sensor RPC provenance and limits

The [origin manifest](hexagonrpc-scratch-origin.json) pins [HexagonRPC at 93f3467dcfe1601bb70547611866a069ae914de5](https://github.com/linux-msm/hexagonrpc/tree/93f3467dcfe1601bb70547611866a069ae914de5) and the [Apollo sensor patch at 4c52c8bc](https://github.com/royka1/Xiaomi-Apollo-pmOS-packages/blob/4c52c8bc8f8bd23a0e31dcd944a15f838777c3e2/hexagonrpcd-apollo/apollo-sensor-fixes.patch). The new patch modifies only `hexagonrpcd/apps_std.c` and retains **Copyright (C) 2023 The Sensor Shell Contributors** and that source file's GPL version 3-or-later notice. Its [COPYING](https://github.com/linux-msm/hexagonrpc/blob/93f3467dcfe1601bb70547611866a069ae914de5/COPYING) is reproduced in [LICENSES](../../LICENSES/README.md). The historical APKBUILD labels the package GPL-2.0-or-later; that metadata is not used to relabel this source or the new patch.

The writable mapping restrictions come from the prior Apollo patch. The R13 addition creates an absent permitted scratch file without truncating an existing one; the existing mode-dependent write path retains truncation/append behavior. Synthetic checks and a short phone observation address that specific failure. There is no general performance comparison, and no private registry/calibration, network data or logs are included. Runtime v6 also completed a fresh RAM boot with the earlier haptic rule and feedbackd access without manual restart. See [R13 lab notes](../../docs/validation-2026-11-01.md#r13--wifi-runtime-v6-and-sensor-scratch-files).
